The GitHub Copilot extension adds the GitHub Copilot desktop app to a Frostyard desktop image. Use it when you want the app on a desktop image. Every image ships the extension switched off.

## Before you start

You need:

- A Frostyard desktop bootc image: Snow, Snowfield, or Sundog, not Floe.
- Root access to enable, update, and remove the extension.
- Network access to `https://repository.frostyard.org/ext/github-copilot/`.
- Free space in `/var` for the download and the installed image.

The GitHub Copilot extension has no published test results on Frostyard images yet. Try it on a machine you can spare first.

## Enable GitHub Copilot

See what Updex found, then enable the feature and download it now:

```bash
updex features list --component=github-copilot
sudo updex features enable github-copilot --now
```

`github-copilot` appears as a component, with its feature disabled. The enable command downloads the image, checks its checksum and signature, links it, and refreshes the merge.

Check the merge and the files that the extension adds:

```bash
systemd-sysext status
command -v github git-credential-copilot
ls '/usr/share/applications/GitHub Copilot.desktop'
```

`systemd-sysext status` lists `github-copilot`. Each name prints a path, and `ls` prints the launcher file.

If `enable --now` exits with a refresh error (`refresh_error` in JSON), the download worked but the merge did not. Run `sudo systemd-sysext refresh`, or reboot. Then run the checks above again.

## Use GitHub Copilot

Start GitHub Copilot from your applications, or run `github`. The launcher runs `github %u`. The extension also ships the `git-credential-copilot` command.

The extension ships no service and adds nothing to `/etc`. The app keeps your settings, credentials, and worktrees in its normal per-user locations.

## Update, roll back, and remove

See whether a newer image exists, then update:

```bash
updex features check --component=github-copilot
sudo updex features update --component=github-copilot
```

The update downloads the newest image and links it. An update swaps `/usr` under the running system. See [Manage system extensions](/docs/sysexts/manage/#update) for the check output and the update timer.

Updex v2.0.6 has no rollback command. See [Manage system extensions](/docs/sysexts/manage/#roll-back) for your options and the planned `updex features rollback` command.

Remove GitHub Copilot now:

```bash
sudo updex features disable github-copilot --now --force
```

Updex unmerges all extensions on the host, deletes the GitHub Copilot image, and merges the rest again. Your settings, credentials, and repositories stay in your home directory. Reboot when the command finishes. Without `--force`, Updex refuses while the image is merged.

## What ships

| Item | What you get |
| --- | --- |
| Package requests | The GitHub Copilot `.deb` (a pinned download), plus `libayatana-appindicator3-1`, `libwebkit2gtk-4.1-0`, and `libgtk-3-0` |
| Version | The image file name carries the `github` package version, plus a `+rN` snosi revision when one is set |
| Commands and launcher | `/usr/bin/github`, `/usr/bin/git-credential-copilot`, and `/usr/share/applications/GitHub Copilot.desktop`; support files are in `/usr/lib/GitHub Copilot` |
| Services | None |
| Image file | `github-copilot_<version>_<os>_<arch>.raw.zst`; `.raw.xz`, `.raw.gz`, and `.raw` also work |
| Download | From `https://repository.frostyard.org/ext/github-copilot/`, signature required (`Verify=true`), into `/var/lib/extensions.d/` |

Each build checks that these paths are present: both commands, the `/usr/lib/GitHub Copilot` directory, the launcher, and the 128-pixel icon. A build that is missing one fails.
