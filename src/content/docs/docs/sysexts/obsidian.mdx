The Obsidian extension adds the Obsidian note-taking app to a Frostyard desktop image. Use it when you want Obsidian on a desktop. Every image carries the extension's definition, switched off. The extension itself is not in the image: Updex turns it on and downloads it.

## Before you start

You need:

- A Frostyard desktop bootc image: Snow, Snowfield, or Sundog, not Floe.
- Root access to enable, update, and remove the extension.
- Network access to `https://repository.frostyard.org/ext/obsidian/`.
- Free space in `/var` for the download and the installed image.

The Obsidian extension has no published test results on Frostyard images yet. Try it on a machine you can spare first.

## Enable Obsidian

See what Updex found, then enable the feature and download it now:

```bash
updex features list --component=obsidian
sudo updex features enable obsidian --now
```

`obsidian` appears as a component, with its feature disabled. The enable command downloads the image, checks its checksum and signature, links it, and refreshes the merge.

Check the merge and the files that the extension adds:

```bash
systemd-sysext status
command -v obsidian
ls /usr/share/applications/md.obsidian.Obsidian.desktop
```

`systemd-sysext status` lists `obsidian`. `command -v` prints a path, and `ls` prints the launcher file.

If `enable --now` exits with a refresh error (`refresh_error` in JSON), the download worked but the merge did not. Run `sudo systemd-sysext refresh`, or reboot. Then run the checks above again.

## Use Obsidian

Start Obsidian from your applications, or run `obsidian`. The extension ships no service and adds nothing to `/etc`.

## Update, roll back, and remove

See whether a newer image exists, then update:

```bash
updex features check --component=obsidian
sudo updex features update --component=obsidian
```

The update downloads the newest image and links it. A refresh replaces `/usr` under a running app, and a running app can fail. Close Obsidian before you run `updex features update`, or update with `--no-refresh` and reboot. See [Manage system extensions](/docs/sysexts/manage/#update) for the check output and the update timer.

Updex v2.0.6 has no rollback command. See [Manage system extensions](/docs/sysexts/manage/#roll-back) for your options and the planned `updex features rollback` command.

Remove Obsidian now:

```bash
sudo updex features disable obsidian --now --force
```

Updex unmerges all extensions on the host, deletes the Obsidian image, and merges the rest again. Your vaults and Obsidian settings stay in your home directory. Reboot when the command finishes. Without `--force`, Updex refuses while the image is merged.

## What ships

| Item | What you get |
| --- | --- |
| Package requests | The Obsidian `.deb` (a pinned download), plus `libxss1` and `xdg-utils` |
| Version | The image file name carries the `obsidian` version |
| Command and launcher | `/usr/bin/obsidian` and `/usr/share/applications/md.obsidian.Obsidian.desktop`; the app lives in `/usr/lib/Obsidian` |
| Services | None |
| Image file | `obsidian_<version>_<os>_<arch>.raw.zst`; `.raw.xz`, `.raw.gz`, and `.raw` also work |
| Download | From `https://repository.frostyard.org/ext/obsidian/`, signature required (`Verify=true`), into `/var/lib/extensions.d/` |

Each build checks that these paths are present: the Obsidian binary, the sandbox helper, the `/usr/bin/obsidian` link, the launcher, and the icon. A build that is missing one fails.
