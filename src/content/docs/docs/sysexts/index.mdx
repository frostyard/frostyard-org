A system extension adds software to the read-only `/usr` of a Frostyard bootc
image. Every image ships each extension switched off. You turn one on with
Updex.

## Find an extension

See what Updex found:

```bash
updex components
updex features list
```

Your image offers only the features it has files for. The catalog below lists
what the repository published at the last sync. If `updex features list` does
not show an extension, your image cannot enable it.

## Enable an extension

Enable one and download it now:

```bash
sudo updex features enable <name> --now
```

Replace `<name>` with the component name from the table. Check the merge:

```bash
systemd-sysext status
```

The output lists the extension you enabled. If `enable --now` exits with a
refresh error (`refresh_error` in JSON), the download worked but the merge did
not. Run `sudo systemd-sysext refresh`, or reboot.

## Update, roll back, and remove

Updex also checks for updates, installs them, and removes an extension again.
A daily timer can download and stage new versions without activating them.
Updex v2.0.6 has no rollback command: you can keep your current version or
remove the extension, and a rollback command is planned. See
[Roll back](/docs/sysexts/manage/#roll-back) and
[Manage system extensions](/docs/sysexts/manage/) for the steps and what to
check after each one.
