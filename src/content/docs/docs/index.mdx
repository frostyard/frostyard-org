Frostyard makes bootc images and `/usr` system extensions, built with
[snosi](https://github.com/frostyard/snosi). These guides cover the Snow
desktop and seven extensions you can turn on: Dev tools, Docker, Incus, K3s,
Nix, Tailscale, and Visual Studio Code. Each page lists its sources at the
bottom.

:::caution[Support boundary]
Secure Boot, signed updates, and signed rollback are not production-ready yet.
Fresh-install test results for Snow, Floe, and Sundog are still pending. See
[Snow](/docs/images/snow/) and the snosi
[Bootc Secure Operations runbook](https://github.com/frostyard/snosi/blob/5b610e3db1017e0ccc9a5dabc10b841e80c1d2e5/docs/bootc-secure-operations.md).
:::

## Install and first boot

Install with Firn. It needs UEFI, erases the disk you pick, and asks you
about each security choice. Start with
[Install a Frostyard image](/install): it covers checking the ISO, the disk
warning, first boot, and MOK enrollment.

Every image checks for updates hourly, stages a new version, and starts it at
your next normal reboot. It never forces a reboot. The
[Snow page](/docs/images/snow/#updates-and-rollback) shows how to check an
update and roll back.

## How a Frostyard system is built

A Frostyard system has three layers:

1. **The image.** It holds the read-only `/usr`, the kernel, the desktop or
   server software, and the updater.
2. **Your state.** `/var` holds homes, containers, and service data. `/etc`
   holds your configuration and carries it into each new version.
3. **System extensions.** EROFS images that add to `/usr` only. They cannot
   write `/etc` or `/var`. An extension keeps its default configuration in
   `/usr/share/factory/etc`, and `tmpfiles.d` copies it into `/etc` at boot.

Every image ships each extension switched off. You turn one on with
[Updex](/docs/tools/updex/); each extension page has the steps.

Each extension page shows the version the catalog listed on its last sync.
The sync takes a pattern match, not a maximum, so it is not always the newest
version. Run `updex features check` to see what you can update to.

## Not covered yet

Snowfield, Sundog, Base, the APT repository, and per-application migrations
have no guide here yet. Extensions other than Dev tools, Docker, Incus, K3s,
Nix, Tailscale, and Visual Studio Code have no guide of their own yet; the
[catalog](/docs/sysexts/) lists every extension.

Old nbc and native A/B installs get no new images or updates after
2026-09-30. They cannot convert in place: back up, install fresh, and restore.
See the snosi
[migration runbook](https://github.com/frostyard/snosi/blob/5b610e3db1017e0ccc9a5dabc10b841e80c1d2e5/docs/nbc-to-bootc-migration.md).
