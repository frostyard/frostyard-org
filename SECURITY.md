# Security policy

This policy covers the frostyard.org website in this repository.

## Supported versions

Only the site that `main` deploys to https://frostyard.org gets fixes. This
repository has no releases, so it has no older version to fix.

## Report a vulnerability

Report a vulnerability privately with GitHub private vulnerability reporting:
https://github.com/frostyard/frostyard-org/security. Use the "Report a
vulnerability" button.

Do not open a public issue for a vulnerability.

A problem in the problem-report intake service belongs to
https://github.com/frostyard/problem-intake/security.

A question about the data in problem reports goes to privacy@frostyard.org.
See https://frostyard.org/privacy/problem-reports/.
